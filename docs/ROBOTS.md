# 로봇 카탈로그

## don2 — 메인 로봇 (정서-욕구 아키텍처용)

소형견 크기 사족보행, **총 3.60kg**, 전 부품 실존 제품 스펙 기반.
정의: [robots/don2/don2.xml](../robots/don2/don2.xml), 스펙/전력모델:
[robots/don2/robot_config.py](../robots/don2/robot_config.py)

### 구동계 (33 액추에이터)
| 부위 | 부품 | 수량 | 스펙 |
|---|---|---|---|
| 힙외전/힙피치/무릎 | Dynamixel XM430-W350 | 12 | 82g, 4.1N·m |
| 발목(종아리 하단 원격장착)·목 2축 | XL430-W250 | 6 | 57g, 1.4N·m |
| 허리 3축(팬/틸트/롤 ±0.35/0.3/0.25) | XM430-W350 | 3 | 상하체 연결 |
| 발가락 텐던 스풀 | XL330-M288 | 12 | 23g, 앞2=종아리·뒤1=허벅지 장착 |

- 몸통: 상체(컴퓨터 RPi4 100g, IMU, 머리)+하체(배터리 3S LiPo 5000mAh 370g) 분리
- 발가락: 발마다 앞2+뒤1, 텐던 굴곡(최대 115도)+스프링 신전, 당김=굽힘 검증됨
- 위치제어 서보 방식(실물 Dynamixel과 동일) — 행동공간 = 목표 관절각

### 감각계 (물리 센서 138 + 내부)
- 전 관절 33쌍 각도/각속도, IMU 9축(지자기 포함)+속도계
- 접촉 31: 머리5 + 몸통10(상/하체 각5) + 발바닥4 + 발가락12 (붉은 패드로 시각화)
- rangefinder 3 (머리 장착: 전방 + 절벽감지 좌/우), 서보 전류 33
- 가상센서 마운트 site: 콧구멍2(냄새), 광센서, 배 밑 바닥색
- 내부(관측 157 = 센서 149 + 높이 + [SoC,전력,고통,충격,손상,아드레날린,코르티솔])

### 전력 (실측 모델)
대기 14.7W(서보 idle 10.8+RPi 3.5+센서 0.35) → 배터리로 약 3.8시간.
보행 20~50W, gen1식 질주 300~500W. τ·ω/효율 기반, 호르몬 배율 적용.

### 몸 세대(변천)
| 세대 | 변경 | 학습 영향 |
|---|---|---|
| v1 | 최초 (발목 서보가 발에, 발판 64mm, 발가락 40mm/약한 텐던) | gen1 스킬 |
| v2 | 발목 서보→종아리(발 77→28g), 발가락 조임 강화(스프링0.08/모멘트암10mm/30N) | toe_curl 재학습 |
| v3 | 발판 22mm(지지는 발가락이), 앞발가락 60mm | gen2~ 전 스킬 |

### 스킬 레퍼토리 (단일 출처: framework/skill_registry.py)
stand · walk(이동 뿌리) · sprint · turn_left · turn_right (walk에서 워름스타트) ·
toe_curl(소근육 별도 계보). 세대/학습 상태는 git log와 models/ 참조.
