# 설계 철학 — 왜 이렇게 만드는가

> "어떻게"는 [framework/DESIGN.md](../framework/DESIGN.md), 그림은 [ARCHITECTURE.md](ARCHITECTURE.md),
> 실증 교훈은 [LESSONS.md](LESSONS.md) 참조.

## 1. 동물형 에이전트 — 명령이 아니라 욕구가 움직인다

이 프로젝트의 로봇은 외부 명령을 수행하는 도구가 아니라, **내부 욕구에 의해 스스로
행동을 선택하는 동물형 에이전트**를 지향한다. 근본 원동력은 고통과 행복이다:

- **고통**: 에너지 고갈, 에너지 급소모, 강한 충격, (예정) 위험 물질 접촉.
  내부상태의 항상성 목표점(setpoint) 이탈로 정의된다.
- **행복**: 기본적으로 **고통의 급격한 해소**(충전, 회복). 인위적 쾌락(맛있는 먹이)도
  있으나 반드시 습관화(중독 방지)를 동반한다.
- 걷기·뛰기 같은 요소행동은 이 동기와 무관하게 인위적 보상으로 학습하되,
  그것을 **언제 왜 쓸지**는 오직 고통/행복의 경제가 결정한다.

같은 환경에서도 다르게 반응하는 개체성은 **호르몬**(아드레날린/코르티솔/도파민형/
세로토닌형)과 개체 기질 프로필이 만든다. 호르몬은 관측(느낌), 고통 가중치(해석),
물리 파라미터(몸)의 세 경로로 작동한다.

## 2. 실존 부품 원칙 — 추상적 부품 금지

크기·무게·전력소모가 없는 순수 추상 액추에이터/부품은 쓰지 않는다. 모든 부품은
**현재 상용화되어 실제로 구현 가능한 제품의 데이터시트 수치**를 모사한다
(Dynamixel 서보의 무게/토크/효율, LiPo 배터리의 용량/질량, RPi의 소비전력...).
전력은 τ·ω/효율로 계산되어 배터리 SoC로 적분되고, 그것이 곧 고통의 근거가 된다.
시뮬레이션의 모든 트레이드오프(빠름=배고픔)가 물리적 근거를 갖게 하기 위함이다.

## 3. 운동의 악보 원칙 — 학습은 상위단만

학습된 운동은 **악보(최적화된 기록)**다: 모듈화되고, 결합되고, 오버로드되고,
재사용된다. 새 운동을 배울 때마다 전체 신경망을 다시 훈련하는 것은 금지한다
(예외: 몸이 바뀐 세대 교체 시의 프리미티브 재구축).

- 결합: 동결 베이스들의 혼합 (walk+turn = 곡선 주행)
- 오버로드: 동결 베이스 + 소형 잔차 (주의 비용 부과 — 개입은 공짜가 아니다)
- 재귀적 모듈화: 쓸만한 합성 운동은 증류(BC)로 굳혀 새 악보로 등록
- 스킬 수정은 **가소성 게이트**(성과 예측오차+호르몬)가 열릴 때만, 챔피언/도전자
  승격 방식으로 (버전업, 퇴행 방지)
- 복합 운동은 **의도적 배치**(행동 프로그램)여야 하며 무작위 혼합이어서는 안 된다.
  지능적 판단이 필요한 배치는 LLM이 숙고 시점에 작성한다 (실시간 루프 밖).

## 4. 발달 커리큘럼 — 아기처럼 배운다

큰 근육의 단순한 움직임부터, 파생 기술은 부모의 체크포인트에서 워름스타트.
단 실측으로 확인된 조건이 있다: **부모 행동이 자식 과제의 구성요소일 때만**
(walk→turn ✓). 부모의 습관을 깨야 하는 길항 관계(stand→walk)에서는 오히려
해로우므로 스크래치로 배운다. → [LESSONS.md](LESSONS.md) #1

## 5. 두뇌 구조 — 대뇌/소뇌의 분업

- **소뇌** = 악보 재생: 빠르고, 자동적이고, 싸다.
- **대뇌** = 의도(프로그램 선택)·개입(잔차)·직접제어(모델 기반 계획): 범용적이지만
  느리고 비싸다.
- 에너지 고통 때문에 **자동화가 내재적으로 이득**이다 — "연습하면 편해진다"의
  동기가 외부 규칙이 아니라 내부 경제에서 나온다.

## 6. 월드 3층 합성과 감각 시그니처

월드 = 지형(Terrain) + 오브젝트(Objects) + 모사 필드(Fields), yaml 레시피로 조립.
**감각 없는 보상/위험 금지**: 쾌/불쾌와 연결된 모든 것은 원거리에서 감지 가능한
시그니처(냄새/빛)를 가져야 한다. 감각 예고는 3층: 원거리(냄새/빛) → 근거리
(바닥색/전방거리) → 접촉(마찰/터치/독성). 시간 변동(낮밤, 희소성)이 있어야
코르티솔·세로토닌 같은 느린 호르몬이 의미를 가진다.

필드 값은 **지각(percept) 층 전용**이며 스킬 정책의 관측에 넣지 않는다 — 스킬은
냄새를 몰라도 되고(방향 판단은 프로그램의 몫), 그 덕에 월드를 확장해도 스킬
재학습이 필요 없다.

## 7. 실험의 단위 — Robot × World × Task

로봇(몸), 월드(무대), 태스크(목표)는 서로를 몰라도 되는 독립 축. 실험은 셋의
조합이고 저장 경로도 조합명을 쓴다. 어느 한 축만 바꿔 재사용하는 것이 기본이다.
